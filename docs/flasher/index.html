Wisp Node

WiFi Spatial Presence for Home Assistant

  1. Plug an ESP32-C3 or ESP32-S3 board into this computer by USB.
  2. Click Install and pick the board's serial port.
  3. When flashing ends, enter your WiFi name and password.
  4. Home Assistant discovers the node. Set its floor and place it on your floor plan in the Wisp integration.
This browser cannot flash boards. Use Chrome or Edge on a computer. Flashing needs a secure (https) page.
